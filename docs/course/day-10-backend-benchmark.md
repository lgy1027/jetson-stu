# Day 14：三后端公平基准

## 今天的问题

怎样比较 PyTorch、ONNX Runtime 与 TensorRT，而不是比较三段不同的代码？

## 你要掌握

- 公平比较固定模型、输入、batch、精度、预热次数和计时边界。
- GPU 计时需同步；端到端计时与纯推理计时要分开。

## 实践

1. 建立统一 benchmark 接口，三个后端共用同一预处理与后处理。
2. 执行预热，再记录至少 100 次推理。
3. 输出 P50、P95、平均值、吞吐和错误计数。
4. 每次 benchmark 记录输入尺寸、功耗模式和必要监控摘要。

## 产物与验收

- `benchmarks/run_inference_benchmark.py`。
- 原始样本与汇总 CSV。
- 同一输入下三后端输出一致性结论。
