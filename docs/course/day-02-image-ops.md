# Day 2：图像变换与结果表达

## 今天的问题

如何把原始像素转换为模型和人都能可靠使用的数据？

## 你要掌握

- resize、crop、normalize 和颜色转换会改变模型看到的数据分布。
- 结果应同时有给人看的可视化和给程序看的 JSON。

## 实践

1. 为 Day 1 程序添加 RGB/BGR 转换、中心裁剪和归一化函数。
2. 用合成 bbox、标签和置信度实现通用标注函数。
3. 将每张图的尺寸、变换参数和模拟检测结果写入 JSON。
4. 为至少两个边界情况写测试：极小图、非标准宽高比或空检测结果。

## 产物与验收

- 可复用的 `perception/image_ops.py`。
- 一张标注图与对应 JSON。
- 两个自动化或可重复边界测试。

## 复盘
