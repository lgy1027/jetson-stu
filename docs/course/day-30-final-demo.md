# Day 30：最终演示与下一阶段边界

## 今天的问题

怎样证明你完成的是一条安全、可复现的仿真闭环，而不是一次偶然跑通？

## 你要掌握

- 演示至少包含成功路径、受控拒绝路径和可复现说明。
- 从离线数据迁移到相机和真实机械臂之前，标定、急停、限位与现场安全需要独立验证。

## 实践

1. 从干净终端按 README 运行成功案例：受约束目标 → 感知 → TF → 仿真规划 → 结构化结果。
2. 演示一个低置信度、缺失 TF 或不可达目标的安全拒绝。
3. 展示 Day 28 指标，并解释当前瓶颈和下一步实验。
4. 写下真实硬件前置清单：相机标定、机械臂模型核对、工作空间、急停和人工监控。

## 产物与验收

- 3–5 分钟演示或等价的截图序列。
- 可复现 README、成功日志、失败日志和指标摘要。
- 一份明确声明“仿真阶段不控制真实设备”的下一阶段清单。

## 复盘

你现在最有把握解释的一个系统边界是什么？下一个要验证的现实假设是什么？
