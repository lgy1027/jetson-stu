# Day 25：感知结果成为候选任务目标

## 今天的问题

怎样将检测结果变成候选目标，同时保留不确定性和坐标条件？

## 你要掌握

- 检测框不是抓取位姿；它至少需要类别、置信度、时间戳、frame_id 和后续几何来源。
- 低置信度或过期结果应阻断规划，而不是勉强继续。

## 实践

1. 定义从检测结果到候选目标的适配器。
2. 让候选目标保留检测来源、置信度和时间戳。
3. 通过 TF2 转换到 base_link，失败即生成 REJECT。
4. 复用 Day 17 的固定内参与模拟深度，把候选像素转换成相机坐标点，再形成带几何来源的规划候选。

## 产物与验收

- 感知→任务目标适配器。
- 一个成功转换和两个拒绝转换测试。
