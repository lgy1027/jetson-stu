# Day 23：确定性任务状态机

## 今天的问题

如何让任务在成功、等待、失败和取消时有明确的下一步？

## 你要掌握

- 状态机把业务流程从模型输出中取回来，变成可测试逻辑。
- 每个状态必须定义输入、允许转移、超时和清理动作。

## 实践

1. 设计状态：VALIDATE、PERCEIVE、TRANSFORM、PLAN、SIMULATE、SUCCEED、REJECT、FAIL。
2. 实现状态转移和事件日志。
3. 为目标缺失、低置信度、TF 错误和规划失败编写测试。
4. 添加取消/超时处理，不让任务无限等待。

## 产物与验收

- `task_planner/state_machine.py`。
- 状态转移图和单元测试。
