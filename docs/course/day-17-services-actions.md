# 可选加深：ROS 2 Service 与 Action

## 今天的问题

何时应使用 topic，何时需要一次请求响应或可取消的长任务？

## 你要掌握

- Service 适合短、明确的请求响应。
- Action 适合长任务、进度反馈和取消，例如处理整段视频或规划动作。

## 实践

1. 设计一个短 service：查询感知节点当前状态或加载输入。
2. 设计一个 action：处理指定视频并反馈已处理帧数。
3. 实现成功、取消和错误路径。
4. 用 CLI 客户端调用并记录反馈。

## 产物与验收

- 一个 service 和一个 action，均有可演示客户端。
- 取消 action 后资源能被正确释放。
