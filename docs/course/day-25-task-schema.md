# Day 22：任务 Schema 与白名单

## 今天的问题

怎样把自然语言目标约束成系统可以验证、审计和拒绝的任务表示？

## 你要掌握

- 自然语言不是执行接口；JSON Schema 是语义层与确定性层之间的契约。
- 白名单技能和显式边界比提示词更可靠。

## 实践

1. 定义任务 Schema：对象、目标区域、技能、置信度、优先级和约束。
2. 定义允许技能，例如 `locate`、`plan_to_pose`、`inspect`；不定义底层电机命令。
3. 为缺字段、未知技能、危险区域和错误类型写验证测试。
4. 为每次拒绝返回机器可读错误码和人可读解释。

## 产物与验收

- `task_planner/task_schema.json`。
- Schema 验证器及成功/失败测试。
