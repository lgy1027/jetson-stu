# Day 26：把安全任务接入 MoveIt 仿真

## 今天的问题

经过 Schema、感知与 TF 检查的目标，怎样才可以请求 MoveIt 规划，而不是直接变成动作？

## 你要掌握

- 任务层只提交 `base_link` 下、带约束的目标位姿；它不提交关节角或底层控制命令。
- MoveIt 的规划结果必须再次检查状态，只有仿真可视化；本阶段不连接真实执行器。

## 实践

1. 取 Day 25 成功案例的结构化目标，验证 schema、时间戳、置信度和 frame_id。
2. 将目标转换到 `base_link`，再检查工作空间白名单。
3. 调用 MoveIt 生成轨迹；记录成功、不可达和碰撞三种结果。
4. 只在 RViz 中展示成功轨迹，并将每一步写入 trace。

## 产物与验收

- `task_planner/plan_adapter.py` 或等价适配层。
- 一个成功仿真规划和两个拒绝结果，均含结构化原因。
- 代码中不存在直接输出关节电流、PWM 或未经检查的关节命令。
