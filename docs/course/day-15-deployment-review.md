# Day 15：部署选择与接口冻结

## 今天的问题

后续 ROS 节点应依赖哪个推理后端，如何避免后端选择污染上层系统？

## 你要掌握

- 上层接口应表达“输入 → 结构化结果”，而不是暴露某个 runtime 的细节。
- 性能、稳定性、构建成本和可维护性共同决定部署选择。

## 实践

1. 汇总 Day 11–14 的正确性、延迟、吞吐和失败记录。
2. 选择一个默认后端，并写出回退策略。
3. 定义统一 `InferenceBackend` 接口或等价抽象。
4. 用相同输入在选定后端运行 Week 1 视频。

## 产物与验收

- `benchmarks/week2-backend-comparison.csv`。
- 一页部署决策记录。
- 后续 ROS 可调用的稳定推理接口。
