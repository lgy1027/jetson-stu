# Day 7：主题与消息设计

## 今天的问题

视觉系统应该发布哪些信息，才能让其他节点无需了解模型实现？

## 你要掌握

- Topic 用于连续数据流；消息字段是模块边界契约。
- 图像、检测结果、时间戳和坐标系应彼此关联。

## 实践

1. 设计离线感知节点的 topic 列表：输入图像、检测结果、运行状态。
2. 使用标准消息或创建最小自定义消息表达检测结果。
3. 发布带时间戳和 frame_id 的数据。
4. 用 `ros2 topic list/echo/hz` 验证消息内容与频率。

## 产物与验收

- topic 契约文档。
- 节点能发布图像元数据和至少一个结构化检测结果。

## 复盘

为什么不能只发布一段给人看的文本，例如“检测到杯子”？
