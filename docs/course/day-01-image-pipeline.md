# Day 1：第一张可复现的处理图片

## 今天的问题

如何把一张输入图片稳定地读取、变换、标注并保存，作为后续感知的最小数据管线？

## 你要掌握

- 图像是 H×W×C 数组；OpenCV 默认 BGR，许多模型使用 RGB。
- 输入校验、固定输出路径和可复现参数比“能显示图片”更重要。

## 实践

1. 在 `perception/` 创建 Python 程序：接受输入图、输出图和目标尺寸参数。
2. 用 OpenCV 读取图片，检查文件是否存在、图像是否为空。
3. 缩放图片、画出尺寸/时间戳文字，并保存到 `perception/outputs/`。
4. 用两张不同尺寸图片运行程序；查看输出，不只看终端是否报错。

## 产物与验收

- `perception/image_pipeline.py`。
- 两张带标注的输出图片。
- 程序在不存在的输入路径时给出清晰错误并返回非零状态。
