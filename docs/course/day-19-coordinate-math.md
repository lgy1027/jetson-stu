# Day 16：坐标变换的数学基础

## 今天的问题

视觉中看到的目标坐标，怎样转换成机器人能够理解的基坐标？

## 你要掌握

- 位姿由平移和旋转组成；齐次变换可组合多个坐标系。
- 变换顺序、单位和右手系约定必须明确。

## 实践

1. 用 NumPy 实现 4×4 齐次变换的构造、组合和逆。
2. 建立已知的 `camera → base_link` 变换和若干 camera 点。
3. 手算一个例子，再用程序验证。
4. 为单位错误、变换顺序错误写测试。

## 产物与验收

- `robot_description/transform_math.py` 与测试。
- 给定 camera 点能输出正确 base_link 点。
