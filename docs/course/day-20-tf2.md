# Day 17：把坐标关系放入 TF2

## 今天的问题

怎样让 ROS 2 中不同模块可靠查询同一时刻的坐标关系？

## 你要掌握

- TF2 是带时间的坐标系变换树。
- `frame_id` 和时间戳不是可选注释，而是变换正确性的条件。

## 实践

1. 发布固定的 `base_link → camera_link` 变换。
2. 发布或模拟一个目标点的 camera frame 表达。
3. 用 TF2 buffer 查询并转换目标到 base_link。
4. 测试 frame 缺失、时间不匹配和树断开的错误路径。

## 产物与验收

- TF 发布与查询节点。
- 正确变换与至少一个失败案例的日志。
