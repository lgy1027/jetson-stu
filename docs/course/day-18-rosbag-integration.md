# Day 10：可回放的离线感知系统

## 今天的问题

如何保存一次输入/输出过程，使 bug 和性能结果能脱离现场复现？

## 你要掌握

- rosbag 记录 topic 数据，不记录你的所有内部状态。
- 可复现回放需要固定配置、版本和输入边界。

## 实践

1. 录制关键输入与输出 topic。
2. 停止实时节点后回放 bag，并让下游节点重新消费。
3. 对比原始运行与回放时的消息数量、时间戳和关键结果。
4. 为本周系统写最小运行说明。

## 产物与验收

- 一个不提交 Git 的 rosbag 目录及生成命令。
- 可从 bag 回放得到检测结果的演示。
- Week 2 总结。
