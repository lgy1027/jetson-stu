# Day 9：参数与 Launch

## 今天的问题

怎样让感知系统不改代码就能切换模型、输入文件和阈值？

## 你要掌握

- 参数用于可配置行为；launch 用于组合多个节点和统一启动方式。
- 配置应被记录，避免“终端里临时改过但无人知道”。

## 实践

1. 为输入路径、模型后端、置信度阈值、输出 topic 添加参数。
2. 为无效参数写验证与报错。
3. 创建 launch 文件启动感知节点及必要辅助节点。
4. 使用 YAML 参数文件保存一个可复现实验配置。

## 产物与验收

- launch 文件与 YAML 配置。
- 一条 launch 命令可启动完整离线感知路径。

## 复盘

什么配置应该做成参数，什么配置应该通过代码/版本控制固定？
