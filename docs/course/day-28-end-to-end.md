# Day 27：第一次端到端闭环

## 今天的问题

怎样把语言任务、感知、TF、状态机和仿真规划连接成一条可观测链路？

## 你要掌握

- 集成时优先连接已经独立验证过的模块，不重写模块内部逻辑。
- 每一层都应输出 trace id、状态和失败原因。

## 实践

1. 输入一个允许的自然语言目标，并转换成已验证的 Schema。
2. 从离线图片/视频取得一个合格感知结果，并结合模拟深度生成相机坐标三维点。
3. 完成 TF 转换、状态机校验与 MoveIt 仿真规划。
4. 输出从输入到规划结果的结构化 trace。

## 产物与验收

- 一条启动或运行命令完成成功案例。
- 端到端日志可指出每个阶段的输入与结果。

## 复盘

哪个模块是整个链路的信任边界？为什么？
