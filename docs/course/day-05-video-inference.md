# Day 5：从单图到视频

## 今天的问题

如何持续处理视频帧，并得到可回放的推理结果？

## 你要掌握

- 视频管线需要区分输入 FPS、处理 FPS 和输出编码。
- 不应把每帧都当作完全独立的离线图片；资源释放和失败帧处理很重要。

## 实践

1. 使用 `cv2.VideoCapture` 逐帧读取一段不少于 1 分钟的视频。
2. 复用 Day 4 的推理与标注代码，写入新视频。
3. 在画面上显示帧号、即时/平均 FPS 和检测数量。
4. 遇到读帧失败时记录原因并正常关闭 writer。

## 产物与验收

- `perception/infer_video.py`。
- 一段不少于 1 分钟的标注输出视频。
- 输出视频可播放，帧数和运行统计合理。
