# Jetson 具身智能课程

本目录保存课程计划与实践课件。课程采用 **Day 0 + 30 个实践单元 + 6 个里程碑**：Day 是稳定编号，不是完成时限；每个单元围绕一个可运行、可检查的产物推进。

## 入口

- [入门必读：Jetson 概念地图](course/foundations.md)
- [课程总计划](course-plan.md)
- [每日课件目录](course/README.md)

## 学习规则

1. 你执行，我讲解、审阅和排障；只有你说“你来执行”时，我才操作 Jetson。
2. 每次只推进当前单元，不提前安装整套依赖。
3. 命令、Docker、监控都是实现工具，不单独占用课程单元。
4. 课件中的“验收”未通过，就先修复，不按日历赶到下一单元。

## 前端四个页面的职责

- **任务卡**：今天解决的问题、必要概念和完成定义；先读它，不执行命令。
- **操作教程**：按小批次给出步骤、命令、预期现象和可展开的真实源码。
- **动手实践**：只保留你需要亲手完成的操作清单。
- **验收**：只判断产物与证据是否齐全，不重复教学。
